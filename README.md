# nvim-bend-syntax

Syntax highlighting and filetype detection for [Bend](https://github.com/bendlang/bend) (`.bend`) in Neovim.

## Install

lazy.nvim:

```lua
{ 'xonecas/nvim-bend-syntax', ft = 'bend' }
```

vim.pack (Neovim 0.12+):

```lua
vim.pack.add({ { src = 'https://github.com/xonecas/nvim-bend-syntax' } })
```

No setup needed.
